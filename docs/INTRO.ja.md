# プロジェクト紹介 · CodeTrail 码途

> **🌐 言語 Language: [中文](INTRO.md) · [English](INTRO.en.md) · [日本語](INTRO.ja.md)**

## 一言での位置づけ

**CodeTrail 码途** は、ローカルブラウザで動作する「コード学習プラットフォーム」です。PC 上の任意のコードディレクトリを、
**学習ロードマップ・AI チューター・進捗追跡**を備えたコースへ自動変換し、ソースコードの体系的な読解・テスト練習・ノート作成を支援します。

## なぜ作ったのか

コードを学ぶときの代表的な痛点:

- オープンソースリポジトリを開いても**どこから読めばいいか分からない** — 手がかりは感覚だけ
- 途中まで読んでも**どこまで進んだか、次は何か**を忘れてしまい、復習の仕組みもない
- 質問や演習の検証には、ツール（エディタ / ターミナル / ノート / ブラウザ）の間を何度も行き来する必要がある

CodeTrail は「スキャン → ロードマップ → 読解 → 質問 → 演習 → 進捗」を単一のローカル・シングルポートアプリに収束させ、
**データは常に自分のマシンに残り**、クラウド依存がなく、AI Key なしでもフルに使えます。

## コア機能

| 機能 | 説明 |
|---|---|
| コース自動生成 | 学習ディレクトリを登録 → ソースリポジトリ / チュートリアル文書を自動判別してコース化 |
| コードインデックス | シンボル抽出（Python AST / JS・Go 正規表現）→ 内部依存グラフ → PageRank 重要度 → 役割判定。トークン消費ゼロのローカル生成 |
| 学習ロードマップ | スマートルート / Markdown ガイドインポート / AI 草案 — 3 源泉で行範囲付きステップを生成 |
| 内蔵 IDE | Monaco 3 ペインワークスペース：ファイルツリー + チャット + エディタ/ステップカード。シンボルアウトライン・ブックマーク・行範囲連携 |
| AI アシスタント | コースコンテキストを携帯するマルチセッション Q&A。Anthropic / OpenAI 互換エンドポイント対応。チュートリアル翻訳は必要に応じて |
| 演習と検証 | 静的チェック（py_compile / node --check / go vet）+ テストチャレンジ（M1 出力比較 / M2 アサーション）、サンドボックス実行 |
| 進捗管理 | 状態マシン + 自己評価（1〜5）+ 復習キュー + ダッシュボードヒートマップ、タブ間でリアルタイム同期 |
| パーソナライズ外観 | セマンティックトークンによる 5 テーマ、ワンクリック切替、ローカルに記憶 |

## 三つの鉄則

1. **データはすべてローカル**: 進捗・ノート・テスト・バックアップはプラットフォームデータディレクトリ（LDD）にのみ保存され、学習者リポジトリには一切書き込みません。
2. **学習リポジトリは読み取り専用**: テストの一時ファイルとバイトコードはすべてプラットフォームディレクトリへリダイレクトされます。
3. **Key なしでも動作**: AI は任意の拡張機能です。API Key を設定しなくても、スキャン・ロードマップ・読解・テスト・進捗の全コア機能は完全に動作します。

## アーキテクチャ

```
┌────────────────────────────┐     シングルポート 127.0.0.1:8787
│  client/  React 18 + TS    │
│  Vite + Monaco + トークン   │──WS──▶  server/  Express + ws
└────────────────────────────┘        node:sqlite + ファイルサービス + 実行サンドボックス
                                      │
                                      ▼
                              <ワークスペースルート>\.learndesk\   （プラットフォームデータ · SQLite + ファイル）
```

- **フロントエンド**: React 18 · TypeScript · Vite · Monaco Editor · react-markdown · 自前テーマシステム
- **バックエンド**: Express · ws（ストリーミング進捗/ログ）· node:sqlite（Node ≥ 22.5）· tsx
- **インデックスと実行**: 自前コードインデクサー（AST + 依存グラフ + PageRank）; 多言語ツールチェーンサンドボックス（uv/go/node）

## 動作要件

- **Node.js ≥ 20**（内蔵 `node:sqlite` のため 22.5+ を推奨）
- 任意: Python（uv）・ Go — 該当コースのテスト / 静的チェック機能用
- 任意: Docker — コンテナでのワンコマンド起動
- 任意: AI API Key — チャット / ロードマップ草案 / 翻訳の強化

## はじめ方

```
1. start.bat で起動 → 設定で学習ルートパスを追加 → コースをスキャン
2. コースを選択 → スマートルート → ワークベンチに学習ロードマップが表示
3. 葉をクリック → AI ビューでコードを読解 → AI に質問 / テスト実行 / 完了マーク
4. ダッシュボードと復習キューのリマインダー → サイクルで前進
```

## 制限と既知の境界

- 単一ディレクトリ 800 項目超は切り詰め、検索は 300 件上限、2MB 超ファイルは先頭 256KB のみデコード — 超大規模 monorepo はサブディレクトリを登録してください
- テスト実行にはローカルの対応ランタイムが必要。ない場合はボタンがインストールヒントを表示
- AI 機能は自分で API Key を用意する必要があります。テーマ/セッション等のブラウザ状態は localStorage に保存され、ブラウザを変えると再設定が必要（データ本体には影響なし）
