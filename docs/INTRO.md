# 项目简介 · CodeTrail 码途

> **🌐 语言 Language： [中文](INTRO.md) · [English](INTRO.en.md) · [日本語](INTRO.ja.md)**

## 一句话定位

**CodeTrail 码途**是一个运行在本机浏览器的「代码学习平台」——把你电脑里的任意代码目录自动变成一门带
**学习路线、AI 助教、进度追踪**的课程，帮助你系统化地读源码、练测试、记笔记。

## 为什么做它

学代码最常见的痛点：

- 打开一个开源仓库，**不知道该从哪个文件看起**，路径引导全靠感觉
- 看到一半**忘了学到哪、下一步是什么**，也没有复习机制
- 想提问、想验证练习，需要在一堆工具之间来回切换（编辑器 / 终端 / 笔记 / 浏览器）

CodeTrail 把「扫描 → 路线 → 阅读 → 提问 → 练习 → 进度」收敛到一个本地单端口应用里，
**数据永远留在自己机器上**，不依赖云服务，不配 AI Key 也能完整使用。

## 核心能力

| 能力 | 说明 |
|---|---|
| 自动课程化 | 登记学习目录 → 自动识别源码仓库 / 教程文档并分类成课程 |
| 代码索引 | 符号提取（Python AST / JS·Go 正则）→ 内部依赖图 → PageRank 重要度 → 角色判定，零 Token 本地生成 |
| 学习路线 | 智能路线 / Markdown 指南导入 / AI 草案，三来源生成带行区间的步骤 |
| 内置 IDE | Monaco 三栏工作区：文件树 + 对话 + 编辑器/步骤卡，符号大纲、书签、行区间联动 |
| AI 助手 | 多会话问答携带课程上下文；可接入 Anthropic / OpenAI 兼容端点；教程翻译按需进行 |
| 练习验证 | 静态检查（py_compile / node --check / go vet）+ 测试闯关（M1 输出比对 / M2 断言脚本），沙箱执行 |
| 进度管理 | 状态机 + 自评（1~5）+ 复习队列 + 看板热力，多标签页实时同步 |
| 个性化外观 | 五套语义令牌主题，一键切换、本机记忆 |

## 三条铁律

1. **数据全在本机**：进度、笔记、测试、备份只存于平台数据目录（LDD），绝不写学习者仓库。
2. **学习仓库只读**：测试执行的临时文件与字节码全部重定向到平台目录。
3. **无 Key 可用**：AI 是可选增强，不配置 API Key 不影响扫描、路线、阅读、测试、进度全部核心功能。

## 技术架构

```
┌────────────────────────────┐     单端口 127.0.0.1:8787
│  client/  React 18 + TS    │
│  Vite + Monaco + 语义令牌   │──WS──▶  server/  Express + ws
└────────────────────────────┘        node:sqlite + 文件服务 + 执行沙箱
                                      │
                                      ▼
                               <工作区根>\.learndesk\   （平台数据·SQLite + 文件）
```

- **前端**：React 18 · TypeScript · Vite · Monaco Editor · react-markdown · 自研主题系统
- **后端**：Express · ws（流式进度/日志）· node:sqlite（Node ≥ 22.5）· tsx
- **索引与执行**：自研代码索引器（AST + 依赖图 + PageRank）；多语言工具链沙箱（uv/go/node）

## 运行要求

- **Node.js ≥ 20**（推荐 22.5+，启用内置 `node:sqlite`）
- 可选：Python（uv）· Go —— 对应课程的测试/静态检查功能
- 可选：Docker —— 容器化一键启动
- 可选：AI API Key —— 对话 / 路线草案 / 翻译增强

## 开箱路径

```
1. start.bat 启动 → 设置添加学习根路径 → 扫描出课程
2. 选课程 → 智能路线 → 工作台出现学习路线图
3. 点叶片 → AI 界面读代码 → 问 AI / 跑测试 / 标记完成
4. 看板与复习队列提醒 → 循环推进
```

## 边界与已知限制

- 单目录 >800 项截断、搜索 300 条上限、>2MB 文件只解码前 256KB——超大 monorepo 建议只登记子目录
- 测试执行要求本机有对应运行时，缺失时按钮给出安装提示
- AI 功能需自备 API Key；主题/会话等浏览器状态存 localStorage，换浏览器需重设（数据本体不受影响）
