# CodeTrail 码途 · 功能介绍（FEATURES）

> 面向：新用户 / 接手维护者。讲清"每个界面能干什么、数据从哪来"。
> 接口细节看 `API.md`，视觉规范看根目录 `DESIGN.md`。

## 0. 它是什么

一个**跑在本机浏览器里的代码学习平台**。你把学习目录（如 `D:\Study`）登记为根路径，它自动扫描出"课程"（源码仓库 / 教程文档），为每个课程构建代码索引、生成学习路线，然后你在 **AI 助手界面**里读代码、问 AI、跑测试、记进度；**工作台**负责一览与路线图，**看板**负责跨课程汇总与复习提醒。

三条铁律：**数据全在本机**（`.learndesk/`）、**学习仓库只读**、**不配 AI Key 也完整可用**（AI 是可选增强）。

## 1. 界面地图（顶栏四键）

```
◈ CodeTrail  [课程胶囊 ▾]      工作台 | 看板 | AI 助手 | 路线      ✓静态检查 👁预览 ⚙设置
```

### 1.1 工作台（主界面）—— "我在哪、往哪走"
- **项目速览**：路线数 / 入口文件 / 核心分 / 累计完成 / 待复习，五格一屏看全课程状态
- **学习路线图（思维导图）**：黑胶囊 = 课程 → 彩色分支 = 每条路线 → 叶片 = 步骤（`文件名 # 中文注释` + 勾选框）。一眼看清"学到哪了、下一步是什么"；**点叶片直达 AI 界面学习该文件**，点分支切换路线
- **任务呈现**：继续学习（各路线第一个未完成步骤）+ 复习队列（自评 ≤3 或完成满 7 天自动入队），点击即跳转
- **问 AI**：右侧滑出**侧边代码助手**（轻量问答，自动携带当前步骤上下文；⤢ 可展开为完整 AI 界面）

### 1.2 AI 助手界面 —— 真正的学习现场（v3.4 定稿分工）
三块，**对话为主体**：
- **对话区（左，~55%）**：多会话（本机保存）、上下文芯片（课程/步骤/文件自动携带）、绿色用户气泡、Markdown+代码块回答、复制/追问
- **步骤卡（右上）**：当前步骤的要点、文件定位（点击 → 编辑器打开并高亮行区间）、**✓ 标记完成（弹 1~5 自评）**、跳过/回改、笔记（Markdown，可写行号引用）
- **文件查阅编辑器（右下）**：Monaco 只读 + 文件 tab（上限 8）+ **⌕ 快速打开**（全库搜索）+ 符号大纲（索引）+ 行号槽**点击加书签** + 渲染/源码切换（md）+ 底栏三件套：**静态检查 / 测试闯关 / 预览**
- 最左缘 🌲：文件树抽屉（懒加载 + 分支色 + 注释列 + 核心文件 PageRank 榜）

### 1.3 看板 —— 跨课程榜单
累计完成大数字、课程榜单卡（语言图标砖 + 排名角标 + 进度药丸 + 路线行）、下一步建议、复习队列、近 30 天像素热力。点路线行 → 回工作台选中该路线。

### 1.4 路线（弹窗）—— 路线从哪来
- **⚡ 智能路线（代码索引）**：零 Token 本地生成——入口 → 核心文件（带行区间与理由）→ 示例，即"AI 自动解析导入的项目生成路线图"的主通道
- **导入 md 指南**：解析标题层级 + `path:L48-L180` 引用为步骤
- **AI 草案**：配 Key 后让模型按仓库结构生成草案，确认后落库
- 步骤编辑器：排序 / 改类型（文件/文档/测试/检查点）/ 行区间 / 要点说明 / 文件存在性校验；支持复制、设默认、删除

## 2. 核心机制

| 机制 | 说明 |
|---|---|
| **代码索引** | aider Repo Map 轻量版：符号提取（Python ast / JS·Go 正则）→ 内部依赖图 → PageRank 重要度 0~100 → 角色判定（core/entry/example/doc/test/config）。驱动：树注释列、核心文件榜、智能路线、符号大纲 |
| **进度状态机** | `todo → doing → done/skipped`；打开步骤即 doing；完成弹自评 1~5；**自评 ≤3 立即入复习队列**，否则 7 天后到期入队；测试通过自动置 done（FR-17/20/21） |
| **测试闯关** | M1 输出比对（期望 stdout 包含/精确 + 退出码）/ M2 断言脚本；沙箱执行（临时文件全重定向平台目录），30s 超时、200KB 截断，WS 流式日志 |
| **静态检查** | py_compile / node --check / go vet，单文件 + 整条路线批量；工具链缺失自动降级提示 |
| **预览** | md/html/静态目录 → 本机 token 服务（5 分钟无访问自动清理），文档课程可整目录预览 |
| **书签/笔记** | 全部存平台数据目录，绝不写学习仓库；笔记按"课程+步骤"幂等一条 |
| **备份迁移** | 一键导出 zip（进度+路线+测试+笔记，不含 AI Key），导入前自动保留原库快照 |

## 3. 五主题外观（v3.1~v3.4）

设置 → 界面：**奶油深绿（默认）/ 浅绿纸 / 墨夜亮绿（全站暗）/ 燕麦榜单 / 白纸蓝调**。任一时刻全站（含编辑器、AI 界面、思维导图）只有一套主题，本机记忆、多标签页同步。颜色全部走语义令牌，界面代码零硬编码色值。

## 5. 典型用户旅程

1. 双击 `start.bat` → 浏览器自动打开 → 设置 → 添加根路径 → 自动扫描出课程
2. 课程胶囊选一门 → 顶栏「路线」→ ⚡ 智能路线（或导入 md）→ 工作台出现思维导图路线图
3. 点叶片 → AI 界面：编辑器已定位到文件与行区间 → 读代码 → 不懂就问（对话区自动带步骤上下文）
4. 学完 → 步骤卡「✓ 标记完成」→ 自评 → （低分自动进复习队列）→ 测试步骤跑「测试闯关」通过即自动打勾
5. 隔几天 → 看板/工作台「复习队列」提醒 → 点进去重学 → 进度多标签页实时同步（WS）

## 6. 边界与已知限制

- 单目录 >800 项截断、搜索 300 条上限、>2MB 文件只解码前 256KB——超大 monorepo 建议只登记子目录
- 测试执行要求本机有对应运行时（uv/go/node），缺失时按钮给出安装提示
- AI 功能需自备 API Key（Anthropic 或 OpenAI 兼容/中转）
- 主题/会话等浏览器状态存 localStorage：换浏览器不迁移（数据本体在 `.learndesk`，不受影响）
