# CodeTrail 码途 — ローカルコード学習プラットフォーム

> **🌐 言語 Language: [中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)**

> ローカルブラウザで動作するコード学習プラットフォーム。ディレクトリを選ぶだけで学習プロジェクトを自動スキャンし、
> 学習ロードマップを生成。内蔵 IDE でコードを読み、AI に質問し、テストを実行し、進捗を記録。
> 複数コースを並行して進め、グローバルなダッシュボードで全体を把握できます。**データはすべて手元に保持し、
> 学習リポジトリは読み取り専用。AI Key なしでもフル機能が使えます。**

## 特徴

- **コース自動スキャン**: 学習ディレクトリを登録するだけで、ソースリポジトリ / チュートリアル文書 / サンプルを自動判別してコース化
- **コードインデックス駆動**: シンボル抽出（Python AST / JS・Go 正規表現）→ 内部依存グラフ → PageRank 重要度順位 → 役割判定（core / entry / example / doc / test）。トークン消費ゼロのローカル生成
- **学習ロードマップ**: 3 つの源泉—スマートルート（入口 → 行範囲付き主要ファイル → サンプル）、Markdown ガイドインポート、AI 草案。ステップエディタ + ファイル存在検証
- **内蔵 IDE リーディングエリア**: Monaco エディタ、3 ペインのドラッグ分割、シンボルアウトライン、ブックマーク（行番号ガタークリック）、大ファイル分割読み、Markdown プレビュー / ソース切替
- **AI アシスタント**: コース / ステップ / ファイルのコンテキストを自動で携帯するマルチセッションチャット。解説・Q&A・ロードマップ生成・チュートリアル翻訳（非コード部分のみ必要に応じて）に対応
- **テストチャレンジ & 静的チェック**: M1 出力比較 / M2 アサーションスクリプト、サンドボックス実行。py_compile / node --check / go vet。WebSocket でのストリーミングログ
- **進捗 & 復習**: 状態マシン + 1〜5 の自己評価。低評価は自動で復習キューへ、7 日後の復習リマインダー。ダッシュボード + 30 日間のピクセルヒートマップ
- **5 つのテーマ**: クリーム（デフォルト）/ ペーパーグリーン / インクナイト / オートミールボード / ペーパーブルー。すべてセマンティックトークンで、ハードコード色はゼロ
- **バックアップ & 移行**: ワンクリック ZIP エクスポート（進捗 + ロードマップ + テスト + ノート、AI Key を含まない）。インポート前に元 DB のスナップショットを自動保存

## クイックスタート

### ローカル起動（推奨）

`start.bat` をダブルクリック（node/uv/go を自動検出 → 初回は依存をインストールしてフロントエンドをビルド → シングルポートで起動）。ブラウザで <http://127.0.0.1:8787> を開きます。

### 手動

```bash
cd client && npm install && npm run build   # 初回のみ
cd ../server && npm install
npm run dev                                  # http://127.0.0.1:8787
```

### Docker（本番）

```bash
docker compose up --build -d
docker compose ps                 # codetrail が healthy になるまで待機
```

<http://127.0.0.1:8787> を開きます。Compose はプラットフォームデータを `codetrail-ldd` 名前付きボリュームに保存し、上位の学習ディレクトリを `/workspace` に読み取り専用でマウントします。初回起動後、設定 → 学習ルートパスで `/workspace` を追加してください。イメージに `.learndesk`・依存キャッシュ・API Key は含まれず、AI 設定はそのデータボリューム内にのみ保存されます。

### 初回の使い方

1. アプリを開く → **設定** → 学習ルートパスを追加（例: `D:\Study`）→ 再スキャン
2. コースピルからコースを選択 → 上部バーの「ロードマップ」→ ⚡ スマートルートでロードマップを生成
3. ロードマップの葉をクリック → AI ビューでエディタがファイル・行範囲に自動位置合わせ → コードを読み、AI に質問し、テストを実行し、進捗を記録

## データとセキュリティ

- **プラットフォームデータディレクトリ（LDD）**: `<ワークスペースルート>\.learndesk\`（`LEARNDESK_DIR` 環境変数で上書き可能）—
  進捗 db.sqlite、settings.json（AI Key を含むためコミット/同期禁止）、routes/ / tests/ / notes/ / backups/ / tmp/。
  **このディレクトリを削除すると全プラットフォームデータが消えます。**
- **学習リポジトリは読み取り専用**: プラットフォームは学習者リポジトリに一切書き込みません（テストの一時ファイル / バイトコードはすべて LDD/tmp へリダイレクト）。
- サービスは `127.0.0.1:8787` のみにバインド。ファイルアクセスはホワイトリスト検証。実行プロセスは 30 秒タイムアウト + 出力 200KB 切り詰め。
- AI Key はローカルの settings.json にのみ保存され、API 応答ではマスクされ、バックアップには含まれません。

## FAQ

- **ページは開くがクリックが反応しない**: ブラウザが旧バージョンをキャッシュしていることが多いので、`Ctrl+F5` で一度ハードリフレッシュしてください。
- **上部に赤い「バックエンド接続断」バナー**: バックエンドが起動していません。`start.bat` を実行し、「サービス準備完了」の表示後にページを更新してください。
- **ポート 8787 が使用中**: すでに別インスタンスが起動しています。<http://127.0.0.1:8787> へアクセスしてください。
- **ファイルが開けない / スキャンが空**: ルートパス設定を確認してください（設定 → ルートパス → 再スキャン）。
